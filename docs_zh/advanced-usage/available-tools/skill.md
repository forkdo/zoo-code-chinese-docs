# skill

`skill` 工具加载并将专项技能指令注入对话上下文。技能为特定任务（如创建 MCP 服务器、自定义模式或遵循标准化工作流）提供详细的、逐步的指引。

---

## 参数

该工具接受以下参数：

- `skill`（必填）：要加载的技能名称（例如 `create-mcp-server`、`create-mode`）。必须与可用技能列表中的技能名称匹配。
- `args`（可选）：传递给技能的、用于定制的额外上下文或参数。

---

## 功能说明

该工具从技能目录中检索技能指令，并将其加载到当前对话中。技能是预先编写好的指令集，指引 Roo 完成复杂的多步骤流程。该工具具备模式感知能力，在可用时会加载特定于当前模式的技能。

---

## 使用场景

- 执行具备标准化工作流的专项流程时
- 创建 MCP 服务器、自定义模式或其他结构化产物时
- 遵循针对特定任务类型的文档化最佳实践时
- 需要调用某一领域的专家知识时
- 任务与系统中某个已知技能模式匹配时

---

## 主要特性

- 模式感知的技能解析（在可用时加载模式专属技能）
- 支持项目级技能覆盖（优先于全局技能）
- 渐进式披露：被链接的文件不会自动加载（需要显式读取）
- 可选参数用于技能定制
- 技能在对话期间持续保留在上下文中
- 为复杂任务提供结构化的、逐步的指引

---

## 工作原理

当调用 `skill` 工具时，它会遵循以下流程：

1. **技能解析**：按以下位置（优先级从高到低）搜索指定名称的技能：
   - 项目 `.roo` 模式专属（例如 `.roo/skills-code/`）
   - 项目 `.roo` 通用（`.roo/skills/`）
   - 项目 `.agents` 模式专属（例如 `.agents/skills-code/`）
   - 项目 `.agents` 通用（`.agents/skills/`）
   - 全局 `.roo` 模式专属（例如 `~/.roo/skills-code/`）
   - 全局 `.roo` 通用（`~/.roo/skills/`）
   - 全局 `.agents` 模式专属（例如 `~/.agents/skills-code/`）
   - 全局 `.agents` 通用（`~/.agents/skills/`）
2. **技能加载**：加载技能的主指令文件（通常为 `SKILL.md`）。
3. **上下文注入**：将技能指令注入对话上下文。
4. **链接文件**：技能中引用的文件**不会**自动加载；Roo 需要在需要时显式读取它们。
5. **执行**：Roo 遵循技能指令完成任务。

---

## 可用技能

技能会根据当前模式和项目配置动态加载。常见技能包括：

- `create-mcp-server`：创建模型上下文协议（Model Context Protocol）服务器的指南
- `create-mode`：创建自定义 Zoo Code 模式的指南
- `find-skills`：帮助发现并安装智能体技能

要查看可用技能，请检查系统提示中的技能列表，或问 Roo"有哪些可用技能？"

---

## 与相关特性的关系

`skill` 工具是 [技能](/features/skills) 特性的编程接口。有关技能的工作原理、如何创建自定义技能以及技能系统架构的完整文档，请参阅[技能特性文档](/features/skills)。

---

## 使用示例

加载技能以创建 MCP 服务器：
```
<skill>
  <skill>create-mcp-server</skill>
  <args>天气 API 集成</args>
</skill>
```

不带额外上下文地加载技能：
```
<skill>
  <skill>create-mode</skill>
</skill>
```
