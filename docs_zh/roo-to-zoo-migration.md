# 从 Roo 迁移到 Zoo

通过两步即可将你的设置从 Roo Code 迁移到 Zoo Code。先从 Roo Code 导出设置文件，然后将同一文件导入到 Zoo Code。

---

## 从 Roo Code 导出

1. 打开 Roo Code 设置。
2. 点击 **Export**。

<img src="/img/roo-to-zoo/roo_export.png" alt="开始从 Roo Code 导出设置" width="600" />

*为何此视图重要：这是 Roo Code 设置导出的开始。*

3. 当保存对话框打开时，选择位置并保存文件。

<img src="/img/roo-to-zoo/roo_export_dialog.png" alt="保存导出的 Roo Code 设置文件" width="600" />

*为何此视图重要：这是 Zoo Code 将要导入的文件。*

导出的文件可能包含敏感设置，包括 API 密钥。请妥善保管。不要分享它。

## 导入到 Zoo Code

1. 打开 Zoo Code。
2. 点击 **Import Settings**。
3. 选择你从 Roo Code 导出的文件。

<img src="/img/roo-to-zoo/zoo_import.png" alt="将导出的 Roo Code 设置文件导入到 Zoo Code" width="600" />

*为何此视图重要：这里是 Zoo Code 加载导出设置文件的位置。*

Zoo Code 导入该文件并将设置合并到你的当前配置中。
