# Zoo Code 3.45.0 Release Notes (2026-01-28)

此版本新增了智能代码折叠（Smart Code Folding）功能，使上下文压缩能够保留你所处理代码的轻量“地图”。

<img
  src="/img/v3.45.0/v3.45.0.png"
  alt="Zoo Code v3.45.0 Release"
  width="600"
/>

## 智能代码折叠

当 Zoo 压缩一段长对话时，现在会为最近使用过的文件保留一个轻量的“代码大纲”——包括函数签名、类声明、类型定义等信息——这样你在压缩之后无需重新共享文件，也能持续准确地引用代码。（感谢 shariqriazz！）([#10942](https://github.com/RooCodeInc/Roo-Code/pull/10942))

> **📚 文档**：详见 [Intelligent Context Condensing](/features/intelligent-context-condensing) 了解如何配置和使用上下文压缩。
