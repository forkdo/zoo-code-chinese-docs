# 在 Zoo Code 中使用 Friendli

Friendli 模型 API 可即时访问精选的模型集，由名为 [Friendli Engine](https://friendli.ai/why-friendliai) 的专有推理栈驱动，提供高性能、高性价比的推理。

**网站：** [https://friendli.ai/](https://friendli.ai/)

---

## 获取 API 密钥

1. **注册/登录：** 前往 [Friendli AI](https://friendli.ai/suite) 创建账户或登录。
2. **进入 API 密钥页面：** 登录后，前往 [个人设置 > API 密钥](https://friendli.ai/suite/~/setting/keys)。
3. **创建密钥：** 生成一个新的 API 密钥。
4. **复制密钥：** 立即复制 API 密钥。你将无法再次看到它。

---

## 可用模型

Zoo Code 支持通过 Friendli AI 平台提供的所有模型。

有关完整、最新的模型列表和规格，请参阅 [Friendli AI 的模型页面](https://friendli.ai/models)。

---

## 在 Zoo Code 中的配置

1. **打开 Zoo Code 设置：** 点击 Zoo Code 面板中的齿轮图标（<Codicon name="gear" />）。
2. **选择提供方：** 从"API Provider"下拉菜单中选择"Friendli"。
3. **输入 API 密钥：** 将你的 Friendli API 密钥粘贴到"Friendli API Key"字段。
4. **选择模型：** 从"Model"下拉菜单中选择你想要的模型。
