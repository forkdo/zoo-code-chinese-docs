# 在 Zoo Code 中使用 Moonshot

Zoo Code 支持通过 Moonshot AI API 访问模型，该 API 提供兼容 OpenAI 的接口。

**网站：** [https://platform.moonshot.cn/](https://platform.moonshot.cn/)

---

## 获取 API 密钥

1.  **注册/登录：** 前往 [Moonshot 平台](https://platform.moonshot.cn/) 创建账户或登录。
2.  **进入 API 密钥页面：** 在平台的 API 密钥板块找到你的 API 密钥。
3.  **创建密钥：** 创建一个新的 API 密钥。为你的密钥取一个描述性名称（例如"Zoo Code"）。
4.  **复制密钥：**  **重要：** 立即复制 API 密钥。  你将无法再次看到它。  请妥善保管。

---

## 可用模型

Zoo Code 支持通过 Moonshot API 提供的所有模型。

有关完整、最新的模型列表，请参阅 [Moonshot 的 API 文档](https://platform.moonshot.cn/docs)。

---

## 在 Zoo Code 中的配置

1.  **打开 Zoo Code 设置：** 点击 Zoo Code 面板中的齿轮图标（<Codicon name="gear" />）。
2.  **选择提供方：** 从"API Provider"下拉菜单中选择"Moonshot"。
3.  **输入 API 密钥：** 将你的 Moonshot API 密钥粘贴到"Moonshot API Key"字段。
4.  **选择模型：** 从"Model"下拉菜单中选择你想要的模型。

---

## 提示与说明

*   **兼容 OpenAI：** Moonshot 使用兼容 OpenAI 的 API 格式，便于与 Zoo Code 集成。
*   **定价：** 有关模型费用和定价详情，请参考 Moonshot 平台。
